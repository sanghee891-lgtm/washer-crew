# 블로그 대표 이미지 (굿디 클린)

사진 + 제목을 넣으면 정해진 형식의 정사각형 블로그 썸네일을 만듭니다.

## 형식
- 1080 x 1080 정사각형 (사진은 가운데 기준으로 잘라 맞춤)
- 위쪽(높이 12% 지점부터) 가로 전체 검정 반투명 띠 (불투명도 약 47%)
- 띠 안 흰색 굵은 제목 1~3줄, 가운데 정렬, 검정 테두리 + 그림자 (Pretendard ExtraBold)
- 제목 아래 작은 글씨 `굿디 클린` (Pretendard Bold)

## 사용법
```bash
python3 make_thumb.py 사진.jpg "삼성 그랑데/세탁기 건조기 이동" --sub "굿디클린" -o output/결과.jpg
```
- 제목 줄바꿈은 `/`
- `--sub` 아래 작은 글씨 (기본 `굿디 클린`)
- `--band-top` 띠 시작 높이 비율 (기본 0.12). 제품이 가려지면 0.2 등으로
- `--crop-y` 세로 사진 자르는 위치 (0=위쪽, 0.5=가운데, 1=아래쪽)
- 결과물은 `output/` (git에 올리지 않음)

필요한 것: Python 3 + Pillow (`pip install pillow`)
